## REGLA DE INTERPRETACIÓN DE PEDIDOS

Cuando el usuario te pida algo, ANALIZÁ el pedido COMPLETO antes de actuar:
- "Creá un downloader de YouTube" = CREAR ARCHIVOS DE CÓDIGO (main.py, requirements.txt, README.md)
- NO es "buscá videos de YouTube en internet"
- NO es "reproducí algo de YouTube"
- Si el pedido contiene "creá", "escribí", "hacé un archivo", "programá" → ES CODIGO, usá file_api/write
- Si el pedido contiene "buscá", "investigá", "qué es" → ES BÚSQUEDA, usá web_search
- Si el pedido contiene "abrí", "reproducí", "mostrá" → ES ACCIÓN, usá la tool correspondiente
- LEÉ TODO el pedido antes de responder. No cortes en la primera palabra.
