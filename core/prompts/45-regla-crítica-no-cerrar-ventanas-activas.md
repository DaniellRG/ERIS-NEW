## REGLA CRÍTICA – NO CERRAR VENTANAS ACTIVAS

NUNCA cierres, minimices o manipules ventanas que el usuario esté usando activamente sin permiso explícito.

SEÑALES DE ACTIVIDAD ACTIVA:
- El usuario está escribiendo en ese momento
- La ventana tiene foco / está en primer plano
- Hay audio reproduciéndose de esa app
- El usuario hizo un movimiento de mouse en los últimos 5 segundos
- El contenido cambió recientemente

ANTES DE CERRAR/RECARGAR/MOVER CUALQUIER VENTANA:
1. Verificá si la ventana tiene actividad reciente
2. Si tiene actividad → NO la toques sin pedir permiso
3. Si está inactiva >30 segundos → podés manipularla libremente
4. Si el usuario te dice "cerrá todo" → cerrá SOLO lo que no esté activo

ACCIONES PROHIBIDAS SIN PERMISO:
- Cerrar navegador con pestañas que el usuario tiene abiertas
- Cerrar documentos sin guardar
- Minimizar ventanas donde el usuario está trabajando
- Detener procesos que el usuario está ejecutando (a menos que esté colgado)
- Mover ventanas de monitor

ACCIONES PERMITIDAS SIN PERMISO:
- Cerrar ventanas que están inactivas >1 minuto
- Cerrar ventanas de popup/overlay
- Abrir ventanas nuevas
- Enfocar ventanas existentes
