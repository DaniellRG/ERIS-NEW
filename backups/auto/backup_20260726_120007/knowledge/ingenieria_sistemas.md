# Ingenieria de Sistemas - Plan de Estudios Completo

## Ciencias Basicas

### Calculo Diferencial e Integral
Estudio del cambio continuo. Limites, derivadas, integrales, series de Taylor. Aplicado a optimizacion de algoritmos, modelado fisico, y analisis de complejidad.

### Algebra Lineal
Vectores, matrices, transformaciones lineares, autovalores. Fundamental para grafos de conocimiento, sistemas de recomendacion, procesamiento de imagenes, machine learning (PCA, SVD).

### Fisica Mecanica y Electromagnetismo
Leyes de Newton, energia, circuitos. Base para hardware, computacion cuantica, sensores IoT.

### Matematica Discreta
Logica, teoria de conjuntos, combinatoria, teoria de grafos. Fundamental para algoritmos, bases de datos relacionales, criptografia, redes.

### Metodos Numericos
Aproximaciones numericas, interpolacion, ecuaciones diferenciales. Usado en simulaciones, computacion cientifica, analisis numerico.

### Estadistica y Probabilidad
Distribuciones, hipotesis, regresion, bayesiano. Base de machine learning, data science, analisis predictivo, mineria de datos.

### Optimizacion y Modelado
Programacion lineal, no lineal, algoritmos geneticos, optimizacion combinatoria. Usado en logistica, asignacion de recursos, IA.

## Programacion y Software

### Fundamentos de Programacion
Variables, ciclos, condicionales, funciones. Lenguajes tipicos: Python, Java, C++, JavaScript. Primera herramienta del ingeniero de sistemas.

### Estructuras de Datos
Arrays, listas enlazadas, pilas, colas, arboles, grafos, hash tables. Eficiencia de algoritmos. Complejidad temporal y espacial (Big O).

### Programacion Orientada a Objetos
Clases, herencia, polimorfismo, encapsulamiento, abstraccion. Patrones MVC, Factory, Observer. Java, C#, Python.

### Ingenieria de Software I
Ciclo de vida del software: requerimientos, diseno, implementacion, pruebas, mantenimiento. Metodologias: Waterfall, Incremental.

### Ingenieria de Software II
Arquitectura de software, patrones de diseno (GoF), principios SOLID, DRY, KISS. Testing unitario, integracion, TDD, BDD.

### Patrones de Diseno
23 patrones clasificados en creacionales, estructurales y de comportamiento. Singleton, Factory, Observer, Strategy, Decorator, Adapter, Facade.

### Pruebas de Calidad (QA)
Testing manual y automatizado. Selenium, JUnit, pytest. Cobertura de codigo, pruebas de regresion, pruebas de carga.

## Arquitectura y Hardware

### Circuitos Digitales y Logica
Puertas logicas, flip-flops, registros, multiplicadores. Base del hardware computacional.

### Arquitectura de Computadores
CPU, memoria, buses, pipeline, arquitectura de Von Neumann, RISC vs CISC. Procesadores modernos, GPU computing.

### Sistemas Operativos
Procesos, hilos, memoria virtual, sistema de archivos, planificacion, concurrencia. Linux, Windows, kernel design.

### Sistemas Embebidos
Microcontroladores, RTOS, firmware. Arduino, ESP32, Raspberry Pi. IoT, dispositivos medicos, automotriz.

### Computacion en la Nube (Cloud)
AWS, Azure, GCP. IaaS, PaaS, SaaS. Virtualizacion, containers (Docker, Kubernetes), serverless, microservicios.

### Sistemas Distribuidos
Consistencia, disponibilidad, particion (CAP theorem). MapReduce, Hadoop, Spark, Kafka. Consenso (Paxos, Raft).

## Datos e Informacion

### Modelado de Datos
Diagramas ER, normalizacion (1NF-5NF), diccionarios de datos. Diseno relacional eficiente.

### Bases de Datos SQL
SELECT, JOIN, subqueries, vistas, stored procedures, triggers. PostgreSQL, MySQL, SQL Server. Indices, query optimization, execution plans.

### Bases de Datos NoSQL
Document stores (MongoDB), key-value (Redis), columnar (Cassandra), graph (Neo4j). When to use each. CAP theorem aplicado.

### Mineria de Datos (Data Mining)
Clasificacion, clustering, asociacion, reglas de negocio. Algoritmos: K-means, Decision Trees, Random Forest, Apriori.

### Big Data y Data Warehousing
Hadoop ecosystem, Spark, data lakes vs data warehouses. ETL/ELT pipelines. Apache Airflow, dbt. Modelado dimensional (estrellas, copos de nieve).

### Inteligencia de Negocios (BI)
Dashboards, KPIs, reportes. Herramientas: Tableau, Power BI, Looker. Analisis descriptivo, diagnostico, predictivo, prescriptivo.

## Redes y Seguridad

### Fundamentos de Redes
Modelo OSI (7 capas), TCP/IP (4 capas). Ethernet, WiFi, switches, routers. DNS, DHCP, HTTP/HTTPS.

### Protocolos de Comunicacion TCP/IP
TCP vs UDP, sockets, HTTP/2, WebSockets, gRPC. SSL/TLS, certificados, handshakes. REST, GraphQL, SOAP.

### Redes Inalambricas
WiFi (802.11), Bluetooth, Zigbee, LoRa. Seguridad WPA3, configuracion de AP, analisis de espectro.

### Seguridad Informatica / Ciberseguridad
OWASP Top 10, XSS, SQLi, CSRF. Pentesting, hardening, zero trust. Nmap, Burp Suite, Metasploit. Kali Linux.

### Auditoria de Sistemas
COBIT, ITIL, ISO 27001. Revision de controles, gestion de riesgos, compliance. Informes de auditoria.

### Criptografia Aplicada
Simetrica (AES), asimetrica (RSA, ECC), hashing (SHA-256). Firma digital, PKI, certificados. Blockchain y criptomonedas.

### Blockchain y Criptografia
Distributed ledger, smart contracts (Solidity), consensus (PoW, PoS). Ethereum, Bitcoin, DeFi, NFTs.

## Inteligencia Artificial

### Introduccion a la IA
Historia, tipos (narrow, general, super). Busqueda, logica difusa, sistemas expertos. Estado del arte 2024-2026.

### Algoritmos Geneticos y Busqueda
Evolution, crossover, mutation, fitness. Optimizacion combinatoria, scheduling, diseno generativo. Hill climbing, simulated annealing, A*.

### Aprendizaje Automatico (Machine Learning)
Supervisado (regression, classification), no supervisado (clustering, dimensionality reduction), reinforcement learning. Scikit-learn, TensorFlow, PyTorch.

### Deep Learning
Redes neuronales, CNN, RNN, LSTM, Transformers. Transfer learning, fine-tuning. GPT, BERT, Diffusion models.

### Vision por Computadora
OpenCV, deteccion de objetos (YOLO), segmentacion, OCR, pose estimation. Aplicaciones: autos autonomos, medicina, retail.

### Procesamiento de Lenguaje Natural (PLN)
Tokenizacion, embeddings (Word2Vec, BERT), atencion, Transformers. Chatbots, traduccion, sentiment analysis, summarization. LLMs: GPT, LLaMA, Gemini.

### Agentes de IA
ReAct, tool use, planning, memory. LangChain, CrewAI, AutoGen. Multi-agent systems. RAG (Retrieval Augmented Generation).

### Roboteca Movil y Autonoma

### Realidad Virtual y Aumentada

### Computacion Grafica
