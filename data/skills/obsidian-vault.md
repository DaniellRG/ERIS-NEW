# Obsidian Vault

## Vault location
`D:\Eris_NEW\BaseDatosObsidian\BaseObsiEris`

## Naming conventions
- **Index notes**: aggregate related topics (e.g., `Skills Index.md`, `Agentes Index.md`)
- **Title case** for all note names
- Folders for organization: `Agentes/`, `Tools/`, `Capacidades/`, `Flujos/`, `Memoria/`, `Configuracion/`
- Use links and index notes to connect related topics

## Linking
- Use Obsidian `[[wikilinks]]` syntax: `[[Note Title]]`
- Notes link to dependencies/related notes at the bottom
- Index notes are just lists of `[[wikilinks]]`

## ERIS Specific
- Each agent has its own folder under `Agentes/`
- Each tool category has its own folder under `Tools/`
- Flujos document how systems interact
- Capacidades document core modules
- Memoria documents the 5 memory systems
- Configuracion documents API keys, voice, and agent config
