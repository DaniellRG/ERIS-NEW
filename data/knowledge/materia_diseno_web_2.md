# Diseño Web II — Guía de estudio (avanzado)

## 1. JavaScript moderno (ES6+)
- let/const, destructuring, spread/rest, template literals, arrow functions.
- Clases, módulos (import/export), variables de entorno en cliente.
- **Promesas**: estado (pending/fulfilled/rejected), .then/.catch/.finally, Promise.all/race/allSettled.
- **async/await**: manejo de errores con try/catch; loops async (for-await-of).
- Closures, hoisting, this y su contexto; call/apply/bind.
- Funciones de orden superior; programación funcional con arrays (map/filter/reduce/find).
- Almacenamiento: localStorage, sessionStorage, cookies; JSON.parse/stringify.
- Eventos avanzados: delegación de eventos, Event object, CustomEvent.
- Fetch API y consumo de servicios REST.

## 2. DOM y manipulación avanzada
- querySelector, closest, data-* attributes, fragmentos, createElement.
- Rendimiento del DOM: reflow/repaint, batched updates, virtual DOM (concepto).
- Intersection Observer, Mutation Observer, Resize Observer.
- Animaciones con CSS transitions y JS (requestAnimationFrame).

## 3. Frameworks y librerías
- **React (introducción)**: componentes, JSX, props, estado (useState), efectos (useEffect), renderizado condicional, listas.
- **Vue (introducción)**: instancia, template, directivas (v-for, v-if, v-model), computed, componentes.
- Comparación y cuándo usar cada uno; SPA (Single Page Application).

## 4. APIs, autenticación y Node.js
- Consumir una API: GET/POST/PUT/DELETE, headers, CORS.
- Autenticación: tokens JWT, sesiones, refresh tokens; manejo seguro en el cliente.
- **Node.js (introducción)**: npm, package.json, módulos, Express (rutas, middlewares, JSON).
- Build tools: bundlers (Vite, webpack), transpiladores (Babel), linting (ESLint), Prettier.

## 5. Diseño responsive y UX
- Media queries avanzadas, breakpoints, mobile-first.
- Flexbox y Grid avanzados (áreas, auto-fit/minmax); unidades clamp().
- Accesibilidad: WCAG (contraste, foco, ARIA, semántica), navegación por teclado.
- Buenas prácticas de UX: jerarquía visual, feedback, carga (skeletons, lazy loading).
- Optimización de performance: minificación, compresión, imágenes (WebP, srcset), lazy load, CDN.

## 6. Seguridad web
- Ataques: **XSS** (prevención: escapar salida, CSP), **CSRF** (tokens), SQL Injection (en backend).
- Headers de seguridad; HTTPS; autenticación segura; cifrado.
- Same-Origin Policy y CORS.

## 7. Git y flujo de trabajo
- Git: init, add, commit, branch, merge, push/pull, clone; conflictos.
- Flujos: GitFlow básico, GitHub Flow; Pull Requests.

## 8. Puntos de examen frecuentes
- Escribir un fetch con async/await y manejo de errores.
- Explicar una promesa y Promise.all con ejemplo.
- Hacer un componente React sencillo con estado.
- Explicar XSS/CSRF y cómo prevenirlos.
- Montar una ruta con Express y un middleware.

## Guía rápida
Si ERIS te pregunta sobre Diseño Web II: cubre JS moderno (promesas, async, DOM),
React/Vue intro, REST y JWT, Node/Express, responsive, accesibilidad, seguridad
web y Git, con ejemplos de código.
