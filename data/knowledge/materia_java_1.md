# Introducción a JAVA — Guía de estudio

## 1. Fundamentos del lenguaje
- Java es orientado a objetos, multiplataforma (JVM), de propósito general.
- JVM (Java Virtual Machine), JRE (entorno de ejecución), JDK (kit de desarrollo).
- "Write once, run anywhere" (WORA); bytecode (.class).
- Compilación: .java → compilador javac → bytecode → JVM.
- Estructura de un programa: clase principal con método main.

## 2. Sintaxis básica
- Tipos primitivos: int, long, short, byte, float, double, char, boolean.
- Variables, constantes (final), operadores, conversión de tipos.
- Control de flujo: if/else, switch, for, while, do-while.
- Cadenas: String (inmutable), métodos (length, charAt, substring, equals).
- Entrada/salida: Scanner, System.out.println.
- Arreglos (arrays) y matrices; bucle for-each.
- Paquetes e import; clases del paquete java.lang automáticamente.

## 3. Programación Orientada a Objetos en Java
- Clases y objetos; atributos y métodos; constructor y this.
- Encapsulamiento: private, public, protected; getters y setters.
- Sobrecarga de métodos (overload).
- Herencia (extends), super, override (@Override).
- Polimorfismo; clases abstractas (abstract) e interfaces (implements).
- Palabra clave static; final (constante / clase no heredable / método no sobreescribible).
- Enumeraciones (enum); clases wrapper (Integer, Double, Boolean).

## 4. Manejo de errores
- Excepciones: try, catch, finally; throws y throw.
- Excepciones comprobadas vs no comprobadas (RuntimeException).

## 5. Colecciones básicas
- ArrayList, LinkedList, HashSet, HashMap.
- Interfaz Collection y Map; recorridos (iterator, for-each).

## 6. Puntos de examen frecuentes
- Diferencia entre JVM, JRE y JDK.
- Diferencia entre clase abstracta e interfaz.
- Diferencia entre ArrayList y array.
- Inmutabilidad de String; diferencia String vs StringBuilder.
- Cómo funciona la herencia y el polimorfismo con ejemplos.
- Significado de static y final.
- Uso de equals vs ==.

## Guía rápida
Si ERIS te pregunta sobre JAVA: cubre JVM/JDK, sintaxis, POO (herencia, interfaces),
excepciones y colecciones, con ejemplos cortos de código y las diferencias clásicas
que suelen salir en exámenes.
