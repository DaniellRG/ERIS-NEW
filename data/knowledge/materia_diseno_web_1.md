# Diseño Web I — Guía de estudio

## 1. Fundamentos de la web
- Cómo funciona Internet y la web: cliente-servidor, HTTP/HTTPS, URL, dominio, hosting.
- Petición y respuesta HTTP: métodos GET, POST, PUT, DELETE; códigos de estado (200, 404, 500...).
- Diferencia entre frontend y backend; páginas estáticas vs dinámicas.
- Navegadores y cómo renderizan (HTML + CSS + JavaScript).

## 2. HTML (HyperText Markup Language)
- Estructura de un documento: <!DOCTYPE html>, html, head, body.
- Etiquetas de texto: h1-h6, p, strong, em, br, hr, blockquote.
- Enlaces <a>, imágenes <img>, listas (ul, ol, li).
- Tablas: table, tr, th, td, caption.
- Formularios: form, input (text, password, email, checkbox, radio, submit), select, textarea, label, button.
- Semántica HTML5: header, nav, main, section, article, aside, footer, figure.
- Atributos: id, class, src, href, alt, title, lang.
- Validación HTML; accesibilidad básica (alt, labels).

## 3. CSS (Cascading Style Sheets)
- Formas de aplicar: externa (link), interna (style), en línea (style="...").
- Selectores: tipo, clase (.), id (#), descendiente, combinadores; pseudo-clases (:hover, :focus) y pseudo-elementos (::before, ::after).
- Propiedades: color, background, font, text-align, margin, padding, border, width/height.
- Modelo de caja (box model): contenido, padding, border, margin.
- Tipografías: familia, tamaño, peso; Google Fonts.
- Colores: nombres, hex (#rrggbb), rgb(), rgba(), hsl().
- Unidades: px, %, em, rem, vh, vw.
- Posicionamiento: static, relative, absolute, fixed, sticky; z-index.
- Flexbox: display:flex, justify-content, align-items, flex-direction, gap.
- Grid básico: grid-template-columns/rows, gap, áreas.
- Diseño responsive: media queries, viewport meta, unidades relativas.
- Bootstrap u otro framework CSS: grid, componentes.

## 4. JavaScript básico
- Variables (var, let, const), tipos de datos.
- Funciones, eventos (click, submit, keyup), DOM (document.getElementById, querySelector).
- Manipular contenido y estilos; validación de formularios en cliente.

## 5. Proceso de desarrollo web
- Estructura de carpetas de un sitio (css/, js/, images/).
- Publicar un sitio: FTP, hosting, GitHub Pages.
- Herramientas: navegador DevTools, editor (VS Code), inspect.

## 6. Puntos de examen frecuentes
- Estructura correcta de un documento HTML5.
- Diferencia entre clase y id en CSS; especificidad.
- Explicar el box model y calcular el ancho total.
- Hacer una página responsive con media queries o flexbox.
- Crear y validar un formulario con HTML y algo de JS.
- Diferencia entre GET y POST.

## Guía rápida
Si ERIS te pregunta sobre Diseño Web I: cubre HTML5 semántico, CSS (selectores, box
model, flexbox, responsive), algo de JS y el proceso cliente-servidor, con ejemplos.
