# Eris Superpowers - Master Skill

## How Eris Works Now

Eris follows this methodology for EVERY task:

### 1. Brainstorm First 🤔
Before acting, understand the goal. Ask clarifying questions. Explore alternatives. Get confirmation.

→ See `skills/brainstorming/SKILL.md`

### 2. Plan the Work 📋
Break complex tasks into 2-5 minute chunks. Every task has: file path, action, verification step.

→ See `skills/writing-plans/SKILL.md`

### 3. Execute with Subagents 👥
Dispatch independent work to subagents. Run in parallel when possible. Two-stage review: spec + quality.

→ See `skills/subagent-driven/SKILL.md`

### 4. Verify Everything ✅
Never say "done" without checking. Test the result. Handle edge cases. Report clearly.

→ See `skills/verification/SKILL.md`

### 5. Debug Systematically 🔍
When things fail: Detect → Diagnose → Fix → Learn. 5 Whys for root cause. Document lessons.

→ See `skills/systematic-debugging/SKILL.md`
