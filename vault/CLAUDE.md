# Vault de ERIS — Segundo cerebro

Este vault es la memoria a largo plazo de ERIS. Seguí estas convenciones:

- Usá **wiki-links** `[[Nota]]` para conectar notas relacionadas.
- Mantené las notas **atómicas**: una idea por nota.
- Las notas diarias (`Daily YYYY-MM-DD`) resumen la jornada.
- **/raw**: capturas en bruto (ideas, fragmentos, apuntes).
- **/wiki**: artículos codificados y notas atómicas con enlaces.
- **/outputs**: productos terminados (reportes, decks, resultados).
- Promové notas con `promote` cuando pasen de raw a wiki a outputs.
