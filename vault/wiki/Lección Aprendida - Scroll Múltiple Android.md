# Aprendizaje sobre Control de Android
## Problema
Al enviar múltiples comandos de swipe (scroll) seguidos a través de `phone_control`, el sistema Android a veces solo ejecuta el primero.

## Solución
Enviar los comandos de swipe individualmente, uno por uno, con una pequeña pausa entre cada comando para asegurar que Android procese cada instrucción correctamente.
