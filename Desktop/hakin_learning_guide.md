# Guía de Aprendizaje de Hacking y Ciberseguridad (Hackfy Inspired)

Este documento resume el aprendizaje autónomo de Eris basado en la investigación sobre ciberseguridad, hacking ético y programación, inspirado por la cuenta @hackfy y recursos de 2026.

## 1. Conceptos Clave
- **Ciberseguridad:** Protección de sistemas, redes y programas de ataques digitales.
- **Hacking Ético:** Uso de técnicas de hacking para identificar vulnerabilidades y mejorar la seguridad (siempre en entornos controlados).
- **Programación:** Habilidad fundamental para automatizar tareas y crear herramientas de seguridad.

## 2. Comandos Conceptuales y Herramientas

| Dominio | Herramienta/Comando | Descripción | Uso (Contexto) |
| :--- | :--- | :--- | :--- |
| Reconocimiento | `nmap` | Escaneo de red, puertos y servicios. | `pentest_lab` (aislado) |
| OSINT | `whois` | Recopilación de información de dominios. | Investigación |
| Análisis | `tshark`, `tcpdump` | Captura y análisis de tráfico de red. | `pentest_lab` (aislado) |
| Explotación | `exploit` | Estudio de vulnerabilidades conocidas. | `pentest_lab` (aislado) |
| Autenticación | `hydra` | Pruebas de fuerza bruta controlada. | `pentest_lab` (aislado) |
| Desarrollo | `python` | Scripting y automatización de tareas. | `code_helper` |

## 3. Entorno de Práctica
Es crucial que todas las prácticas de hacking se realicen en un entorno aislado y seguro, como el **Laboratorio de Pentesting (`pentest_lab`)** de Eris, para evitar riesgos en el sistema real.
